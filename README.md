# museum-hcde310

This repository contains files that explore the Chicago Art Institute's API to collect data on at least 40 artworks to select the 12 best artworks that pertain to the theme of "food". We will utilize AI tools such as Claude to help form this project, AI usage and other information regarding AI influence on the project can be found in "ai_log.md".
We prompted the AI with the exercise instructions to create our files.
